# 🏭 Содо-Хлорат - Портал Сотрудника

Современный веб-портал для сотрудников химической компании "Содо-Хлорат". Приложение предоставляет доступ к графику работы, информации о заработной плате и новостям компании.

## ✨ Особенности

- 📅 **График работы** - просмотр личного расписания смен
- 💰 **Заработная плата** - детальная информация о начислениях и удержаниях
- 📰 **Новости компании** - актуальные новости и объявления
- 📊 **Статистика** - ключевые показатели работы сотрудника
- 🎨 **Современный дизайн** - корпоративные цвета (белый и тёмно-синий)
- 🇷🇺 **Полная русификация** - весь интерфейс на русском языке
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 🚀 Быстрый старт

### Требования

- Node.js версии 18.0 или выше
- npm или yarn

### Установка

1. Клонируйте репозиторий (или перейдите в директорию проекта):
```bash
cd /workspace
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение в режиме разработки:
```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## 📦 Сборка для продакшена

Создайте оптимизированную сборку для продакшена:

```bash
npm run build
```

Предварительный просмотр собранного приложения:

```bash
npm run preview
```

## 👤 Демо-данные

Приложение использует демонстрационные данные для:
- Профиля сотрудника (Иванов Иван Петрович, Инженер-технолог)
- Графика работы на текущую неделю
- Информации о заработной плате за октябрь 2025
- Последних новостей компании

## 🔧 Настройка

Вы можете изменить данные в файле `src/App.jsx`:

- `employee` - информация о сотруднике
- `schedule` - график работы
- `salary` - данные о зарплате
- `news` - новости компании
- `stats` - статистика
