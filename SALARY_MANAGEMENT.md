# 💰 Управление зарплатой сотрудников Сода-Хлорат

## 🏗️ Структура зарплаты

Каждый сотрудник имеет персональную структуру зарплаты, состоящую из:

### **Основные компоненты:**
- **Оклад** (`baseSalary`) - базовая ставка
- **Премия** (`bonus`) - дополнительные выплаты
- **Надбавка за ночное время** (`nightShift`) - работа в ночную смену
- **Надбавка за вредность** (`hazardPay`) - работа с вредными веществами
- **Переработки** (`overtime`) - сверхурочные часы
- **Работа в праздничные дни** (`holidayWork`) - работа в выходные/праздники

### **Рабочие часы:**
- **Обычные часы** (`regular`) - стандартное рабочее время
- **Ночные часы** (`night`) - работа с 22:00 до 06:00
- **Переработка** (`overtime`) - сверхурочные часы
- **Праздничные дни** (`holiday`) - работа в выходные/праздники

## 📊 Примеры расчета зарплаты

### **Инженер-химик (Производство)**
```javascript
salary: {
    baseSalary: 60000,        // Оклад
    bonus: 10000,             // Премия за выполнение плана
    nightShift: 5000,         // 20 часов ночной работы
    hazardPay: 8000,          // Надбавка за вредность
    overtime: 3000,           // 8 часов переработки
    holidayWork: 2000,        // 4 часа в праздники
    total: 88000              // Итого
}
```

### **Лаборант (Лаборатория)**
```javascript
salary: {
    baseSalary: 45000,        // Оклад
    bonus: 5000,              // Премия
    nightShift: 0,            // Нет ночных смен
    hazardPay: 3000,          // Надбавка за вредность
    overtime: 1000,           // 4 часа переработки
    holidayWork: 0,           // Нет работы в праздники
    total: 54000              // Итого
}
```

### **Оператор установки (Сменный график)**
```javascript
salary: {
    baseSalary: 45000,        // Оклад
    bonus: 5000,              // Премия
    nightShift: 8000,         // 40 часов ночной работы
    hazardPay: 6000,          // Надбавка за вредность
    overtime: 2000,           // 8 часов переработки
    holidayWork: 1000,        // 2 часа в праздники
    total: 67000              // Итого
}
```

## 🔧 Как изменить зарплату сотрудника

### **Способ 1: Редактирование файла `employees-data.js`**

1. **Откройте файл `employees-data.js`**
2. **Найдите нужного сотрудника по ID или имени**
3. **Измените значения в объекте `salary`:**
   ```javascript
   salary: {
       baseSalary: 65000,        // Новый оклад
       bonus: 12000,             // Новая премия
       nightShift: 6000,         // Надбавка за ночное время
       hazardPay: 9000,          // Надбавка за вредность
       overtime: 4000,           // Переработки
       holidayWork: 2500,        // Работа в праздники
       total: 98500              // Общая сумма
   }
   ```
4. **Сохраните файл**
5. **Обновите страницу в браузере**

### **Способ 2: Изменение рабочих часов**

```javascript
workHours: {
    regular: 160,             // Обычные часы
    night: 25,                // Ночные часы (увеличить)
    overtime: 12,             // Переработка (увеличить)
    holiday: 6                // Праздничные дни (увеличить)
}
```

## 📈 Автоматический расчет

Система автоматически рассчитывает:
- **Общую сумму зарплаты** на основе всех компонентов
- **Статистику по часам** для отображения
- **Историю выплат** с вариациями

### **Формулы расчета:**
- **Ночная надбавка**: `ночные_часы × базовая_ставка × 0.2`
- **Надбавка за вредность**: `обычные_часы × базовая_ставка × 0.15`
- **Переработка**: `сверхурочные_часы × базовая_ставка × 0.5`
- **Праздничные дни**: `праздничные_часы × базовая_ставка × 1.0`

## 🎯 Рекомендации по настройке

### **Для производственных рабочих:**
- Высокая надбавка за вредность (15-20%)
- Надбавка за ночные смены
- Премии за выполнение плана

### **Для лабораторных сотрудников:**
- Средняя надбавка за вредность (10-15%)
- Премии за качество анализов
- Минимальные ночные смены

### **Для управленческого персонала:**
- Высокий базовый оклад
- Премии за достижение целей
- Минимальные надбавки за условия

### **Для сменных рабочих:**
- Высокие надбавки за ночное время
- Надбавки за работу в выходные
- Премии за стабильность

## 🔍 Проверка расчетов

### **Проверьте правильность:**
1. **Общая сумма** = Оклад + Премия + Все надбавки
2. **Надбавки соответствуют** отработанным часам
3. **Статус сотрудника** влияет на выплаты
4. **Отдел** определяет базовые надбавки

### **Типичные ошибки:**
- ❌ Неправильный расчет общей суммы
- ❌ Несоответствие часов и надбавок
- ❌ Отсутствие обновления после изменений
- ❌ Неправильный формат чисел
