# Личный кабинет сотрудника Soda-Chlorate

Веб-приложение для личного кабинета сотрудников химической компании Soda-Chlorate.

## Особенности

- **Современный дизайн** с использованием белого и темно-синего цветов
- **Русскоязычный интерфейс** для удобства сотрудников
- **Адаптивный дизайн** для работы на различных устройствах
- **Темная тема** для комфортной работы в любое время суток

## Функциональность

### 📅 Расписание
- Просмотр недельного расписания работы
- Навигация между неделями
- Отображение смен (дневная, вечерняя, ночная)
- Выходные дни

### 💰 Зарплата
- Текущая зарплата за месяц
- Количество отработанных часов
- Детализация выплат (оклад, премия, доплаты)
- История выплат за предыдущие месяцы

### 📰 Новости компании
- Последние новости и объявления
- Поиск по новостям
- Категоризация новостей (безопасность, мероприятия, развитие, производство)
- Интерактивные элементы

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные стили с Flexbox и Grid
- **JavaScript (ES6+)** - интерактивность и динамические функции
- **Font Awesome** - иконки
- **Адаптивный дизайн** - поддержка мобильных устройств

## Установка и запуск

1. Скачайте все файлы проекта
2. Откройте `index.html` в веб-браузере
3. Приложение готово к использованию!

## Структура проекта

```
├── index.html          # Основная HTML-страница
├── styles.css          # Стили приложения
├── script.js           # JavaScript функциональность
└── README.md           # Документация
```

## Использование

### Навигация
- Используйте вкладки в верхней части для переключения между разделами
- Горячие клавиши: Alt+1 (Расписание), Alt+2 (Зарплата), Alt+3 (Новости)

### Расписание
- Кнопки "←" и "→" для навигации между неделями
- Цветовая индикация смен:
  - 🟢 Зеленая полоса - дневная смена
  - 🔴 Красная полоса - вечерняя смена
  - 🟣 Фиолетовая полоса - ночная смена

### Зарплата
- Карточки с основной информацией о зарплате
- Детальная разбивка по статьям доходов
- Таблица с историей выплат

### Новости
- Поле поиска для фильтрации новостей
- Цветные теги для категоризации
- Интерактивные карточки новостей

## Дополнительные функции

- **Темная тема** - переключение в правом верхнем углу
- **Уведомления** - система уведомлений для важных событий
- **Анимации** - плавные переходы между разделами
- **Поиск** - поиск по новостям компании
