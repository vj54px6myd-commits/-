# Личный кабинет сотрудника Soda-Chlorate

Веб-приложение для личного кабинета сотрудников химической компании Soda-Chlorate.

## Описание

Это современное веб-приложение, разработанное специально для сотрудников компании Soda-Chlorate, работающей в химической отрасли. Приложение предоставляет удобный доступ к личной информации сотрудника, включая расписание работы, информацию о зарплате и корпоративные новости.

## Основные функции

### 📅 Расписание работы
- Интерактивное расписание с возможностью навигации по неделям
- Отображение рабочих смен, обеденных перерывов и выходных дней
- Адаптивный дизайн для удобного просмотра на всех устройствах

### 💰 Информация о зарплате
- Текущая зарплата и премии
- История выплат за последние месяцы
- Информация о следующей выплате
- Красивые карточки с ключевыми показателями

### 📰 Корпоративные новости
- Актуальные новости компании
- Различные категории новостей (Важное, Достижения, События, Экология)
- Выделение важных новостей
- Адаптивный дизайн для удобного чтения

## Технические особенности

- **Адаптивный дизайн**: Приложение корректно отображается на всех устройствах
- **Современный UI/UX**: Использование градиентов, теней и плавных анимаций
- **Русская локализация**: Полностью русскоязычный интерфейс
- **Цветовая схема**: Белый и темно-синий цвета в соответствии с брендингом компании
- **Интерактивность**: Плавные переходы и hover-эффекты

2. Откройте `index.html` в веб-браузере
3. Приложение готово к использованию!
