# 📋 Управление базой сотрудников Soda-Chlorate

## 📁 Расположение файлов

### Основные файлы:
- `employees-data.js` - **ОСНОВНОЙ ФАЙЛ** с базой данных сотрудников
- `script.js` - логика работы приложения
- `index.html` - интерфейс приложения

## 🔧 Как добавить нового сотрудника

### Шаг 1: Откройте файл `employees-data.js`

### Шаг 2: Найдите массив `EMPLOYEES_DATABASE` и добавьте нового сотрудника

```javascript
{
    id: 9, // Увеличьте ID на 1 от последнего
    name: "Имя Фамилия",
    position: "Должность",
    department: "production", // Выберите из списка ниже
    departmentName: "Название отдела",
    email: "email@soda-chlorate.ru",
    phone: "+7 (495) 123-45-XX",
    status: "working", // Выберите из списка ниже
    statusName: "На работе",
    schedule: "Пн-Пт: 08:00 - 17:00",
    avatar: "ИФ", // Инициалы (2 буквы)
    hireDate: "2024-01-01",
    salary: 50000
}
```

## 📊 Параметры сотрудника

### Обязательные поля:
- `id` - уникальный номер (увеличивайте на 1)
- `name` - полное имя
- `position` - должность
- `department` - код отдела (см. список ниже)
- `departmentName` - название отдела
- `email` - корпоративная почта
- `phone` - рабочий телефон
- `status` - статус (см. список ниже)
- `statusName` - название статуса
- `schedule` - график работы
- `avatar` - инициалы (2 буквы)

### Дополнительные поля:
- `hireDate` - дата приема на работу (YYYY-MM-DD)
- `salary` - зарплата (число)

## 🏢 Отделы (department)

| Код | Название |
|-----|----------|
| `production` | Производство |
| `laboratory` | Лаборатория |
| `quality` | Контроль качества |
| `safety` | Безопасность |
| `management` | Управление |

## 👤 Статусы сотрудников (status)

| Код | Название | Цвет |
|-----|----------|------|
| `working` | На работе | 🟢 Зеленый |
| `vacation` | В отпуске | 🟡 Желтый |
| `sick` | На больничном | 🔴 Красный |
| `offline` | Не на работе | ⚫ Серый |

## 🔄 Как изменить данные существующего сотрудника

1. Найдите сотрудника в массиве `EMPLOYEES_DATABASE` по ID или имени
2. Измените нужные поля
3. Сохраните файл
4. Обновите страницу в браузере

## 🗑️ Как удалить сотрудника

1. Найдите запись сотрудника в массиве
2. Удалите всю запись (включая фигурные скобки и запятую)
3. Сохраните файл
4. Обновите страницу в браузере

## ⚠️ Важные замечания

1. **Всегда делайте резервную копию** файла `employees-data.js` перед изменениями
2. **ID должны быть уникальными** - не повторяйте номера
3. **Email должны быть уникальными** - проверяйте, что адрес не занят
4. **Сохраняйте формат** - не забывайте запятые и фигурные скобки
5. **После изменений** обновите страницу в браузере (F5)

## 🚀 Автоматизация (для продвинутых пользователей)

Если у вас много сотрудников, можно:
1. Создать CSV файл с данными
2. Написать скрипт для конвертации в JavaScript
3. Или использовать базу данных (MySQL, PostgreSQL) вместо файла

## 📞 Поддержка

При возникновении проблем:
1. Проверьте синтаксис JavaScript (откройте консоль браузера F12)
2. Убедитесь, что все запятые и скобки на месте
3. Проверьте, что ID уникальны
4. Восстановите файл из резервной копии
