# 📋 План добавления новых сотрудников

## 🔧 Что нужно указать для автоматического добавления:

### 1. **Основная информация:**
- **name** - Полное имя (например: "Иванов Иван Иванович")
- **email** - Уникальный email адрес
- **phone** - Номер телефона (например: "+7 (495) 123-45-67")
- **position** - Должность (например: "Инженер-химик")
- **department** - Отдел (production, laboratory, quality, safety, management)

### 2. **Рабочие данные:**
- **shift** - Смена (morning, day, night)
- **hireDate** - Дата приема на работу (формат: "2024-01-15")
- **status** - Статус (working, vacation, sick) - по умолчанию "working"

### 3. **Уровень доступа:**
- **accessLevel** - Уровень доступа (employee, manager, admin)

### 4. **Заработная плата (индивидуальная):**
- **baseSalary** - Оклад (руб/месяц) - **ИНДИВИДУАЛЬНО ДЛЯ КАЖДОГО**
- **bonusPercent** - Процент премии (по умолчанию 47%)
- **hazardPay** - Надбавка за вредность (руб/месяц, по умолчанию 0)

## 💰 Система расчета зарплаты:

### **Автоматические расчеты:**
- **Премия** = Оклад × 47% (стандарт)
- **Ночная смена** = Оклад × 40% (только для ночной смены)
- **Утренняя/дневная смена** = без надбавок
- **Праздничные дни** = Оклад × 100% за каждый час
- **Переработки** = Оклад × 50% за каждый час

### **Формула итоговой зарплаты:**
```
Итого = Оклад + Премия + Надбавка за смену + Вредность + Переработки + Праздники
```

## 🚀 Как использовать:

1. **Подготовьте данные** в формате JSON
2. **Вызовите функцию** `addEmployeeAutomatically(employeeData)`
3. **Проверьте результат** - функция вернет объект с результатом

## ⚠️ Важные моменты:

- **Email должен быть уникальным** - система проверит на дубликаты
- **Оклад индивидуален** - укажите конкретную сумму для каждого сотрудника
- **Премия 47%** - применяется ко всем, если не указано иное
- **Ночная смена +40%** - автоматически применяется для night shift
- **Права доступа** - только менеджеры и администраторы могут добавлять сотрудников

## 🔍 Проверка добавления:

После добавления сотрудника система:
1. ✅ Проверит уникальность email
2. ✅ Рассчитает зарплату автоматически
3. ✅ Обновит список сотрудников
4. ✅ Вернет результат операции
