# Система смен Soda-Chlorate

## 📋 Обзор

В портале Soda-Chlorate реализована система трех смен для сотрудников:

### 🕐 Типы смен

| Смена | Время работы | Код | Описание |
|-------|-------------|-----|----------|
| **Утренняя** | 7:30 - 19:30 | `morning` | 12-часовой рабочий день |
| **Дневная** | 8:00 - 17:00 | `day` | Стандартный 8-часовой рабочий день |
| **Ночная** | 19:30 - 7:30 | `night` | 12-часовой ночной рабочий день |

## 💰 Расчет зарплаты по сменам

### Базовые надбавки:
- **Утренняя смена**: +10% к базовой ставке за все рабочие часы
- **Ночная смена**: +20% к базовой ставке за все рабочие часы  
- **Дневная смена**: без дополнительных надбавок

### Пример расчета:
```
Сотрудник с окладом 50,000 ₽:
- Дневная смена: 50,000 ₽ (базовая ставка)
- Утренняя смена: 55,000 ₽ (+10% = 5,000 ₽)
- Ночная смена: 60,000 ₽ (+20% = 10,000 ₽)
```

## 🔧 Управление сменами

### Добавление нового сотрудника:

1. **В форме регистрации** выберите смену из выпадающего списка
2. **В файле `employees-data.js`** добавьте поля:
   - `shift`: код смены (`morning`, `day`, `night`)
   - `shiftName`: название смены
   - `schedule`: время работы

### Изменение смены существующего сотрудника:

1. Откройте файл `employees-data.js`
2. Найдите сотрудника по ID
3. Измените поля `shift`, `shiftName`, `schedule`
4. Пересчитайте зарплату с учетом новой смены

## ⚠️ Важные замечания

1. **Смена влияет на зарплату** - при изменении смены пересчитайте зарплату
2. **Время работы** должно соответствовать типу смены
3. **Цветовая индикация** помогает быстро определить тип смены
4. **Ночная смена** имеет наибольшую надбавку (20%)
5. **Утренняя смена** имеет среднюю надбавку (10%)

## 🔍 Диагностика

Если смены не отображаются правильно:

1. Проверьте файл `employees-data.js` на наличие полей `shift` и `shiftName`
2. Убедитесь, что коды смен правильные: `morning`, `day`, `night`
3. Проверьте консоль браузера на ошибки JavaScript
4. Используйте `debug.html` для диагностики системы
