# Функции управления сотрудниками - Soda-Chlorate Employee Portal

## Обзор

Модуль управления сотрудниками предоставляет полный функционал для просмотра, добавления, редактирования и управления информацией о сотрудниках компании Soda-Chlorate.

## Основные функции

### 📋 Список сотрудников

**Возможности:**
- Таблица с полной информацией о сотрудниках
- Сортировка по всем колонкам (имя, должность, отдел, email, телефон, дата приема, статус)
- Поиск по имени, фамилии, email или должности
- Фильтрация по отделам
- Пагинация для больших списков
- Экспорт данных в CSV

**Отображаемая информация:**
- Фото/аватар сотрудника (инициалы)
- Имя и фамилия
- Должность
- Отдел
- Email
- Телефон
- Дата приема на работу
- Статус (Активен, Неактивен, В отпуске)

### 📊 Статистика

**Карточки статистики:**
- Общее количество сотрудников
- Количество активных сотрудников
- Количество отделов

### 🔍 Поиск и фильтрация

**Поиск:**
- Поиск в реальном времени
- Поиск по имени, фамилии, email, должности
- Задержка 500мс для оптимизации запросов

**Фильтры:**
- Фильтр по отделам
- Все отделы
- Производство
- Контроль качества
- Логистика
- HR
- Управление

### ➕ Добавление сотрудников

**Форма добавления включает:**
- Имя и фамилия (обязательно)
- Email (обязательно)
- Телефон
- Должность (обязательно)
- Отдел (обязательно)
- Дата приема на работу (обязательно)
- Зарплата
- Примечания

**Валидация:**
- Проверка обязательных полей
- Валидация email
- Валидация номера телефона

### ✏️ Редактирование сотрудников

**Возможности:**
- Редактирование всех полей сотрудника
- Сохранение изменений
- Валидация данных

### 👁️ Просмотр детальной информации

**Модальное окно с информацией:**
- Полное имя и должность
- Статус с цветовой индикацией
- Контактная информация (email, телефон)
- Отдел
- Дата приема на работу
- Зарплата
- Примечания

### 🗑️ Удаление сотрудников

**Безопасное удаление:**
- Подтверждение перед удалением
- Обновление статистики после удаления

### 📤 Экспорт данных

**Экспорт в CSV:**
- Все видимые данные
- Форматирование для Excel
- Автоматическое именование файла с датой

## Технические особенности

### 🏗️ Архитектура

**Модульная структура:**
- `employees.js` - основной модуль управления
- `api.js` - API функции для работы с сервером
- `data-manager.js` - кеширование и управление данными
- `sample-data.js` - тестовые данные

### 🔄 API интеграция

**Endpoints:**
```
GET    /api/v1/employees              - Список сотрудников
GET    /api/v1/employees/{id}         - Информация о сотруднике
POST   /api/v1/employees              - Создание сотрудника
PUT    /api/v1/employees/{id}         - Обновление сотрудника
DELETE /api/v1/employees/{id}         - Удаление сотрудника
GET    /api/v1/employees/stats        - Статистика
GET    /api/v1/departments            - Список отделов
```

**Параметры запросов:**
- `page` - номер страницы
- `limit` - количество записей на странице
- `search` - поисковый запрос
- `department` - фильтр по отделу

### 💾 Кеширование

**Стратегия кеширования:**
- Кеширование на 5 минут
- Автоматическая инвалидация при изменениях
- Офлайн поддержка с кешированными данными

### 📱 Адаптивность

**Responsive дизайн:**
- Адаптивная таблица с горизонтальной прокруткой
- Мобильная навигация
- Оптимизированные модальные окна

## Использование

### Инициализация

```javascript
// Модуль автоматически инициализируется при загрузке страницы
// Доступен через window.employeesManager
```

### Программное управление

```javascript
// Загрузка сотрудников
await window.employeesManager.loadEmployees();

// Загрузка с параметрами
await window.employeesManager.loadEmployees(1, 20, 'Иван', 'production');

// Просмотр сотрудника
await window.employeesManager.viewEmployee(1);

// Редактирование сотрудника
await window.employeesManager.editEmployee(1);

// Удаление сотрудника
await window.employeesManager.deleteEmployee(1);
```

### События

```javascript
// Слушатель изменений
window.employeesManager.addEventListener('employeesUpdated', (event) => {
    console.log('Список сотрудников обновлен');
});
```
